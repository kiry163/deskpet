# deskpet —— 技术选型、现状与路线图

> 状态：**现行**（2025-12 更新，对齐「控制台与配置重构」方向）。
> 本文只记录三类内容：**技术选型与理由**、**当前状态（已完成）**、**后续路线（要做什么）**。
> 配套文档：[需求规格](需求规格.md)。

---

## 1. 技术选型与理由

### 1.1 历史（简要）

- 曾选 **Tauri v2 + React/PIXI 序列帧**（M0 原型验证通过）→ **弃用**：
  VP9+alpha webm 无法用 ffmpeg 转帧（alpha 丢失）需自研工具、序列帧膨胀（≈430MB）、
  壳层 + 前端渲染带来运行时依赖与体积开销。
- 现行为**纯原生**：Windows Win32 / macOS AppKit。

### 1.2 现行决策

| 决策项 | 结论 | 理由 |
|---|---|---|
| 壳层 | 纯原生 Win32 / AppKit | 单文件自包含、零运行时依赖、启动快、性能上限高 |
| 渲染 | libvpx 静态链接直接解码 webm，逐像素合成（`UpdateLayeredWindow` / `CGBitmapContext`）| 素材即用不转帧；alpha 存于 BlockAdditional 扩展（ffmpeg 会丢），必须 libvpx 层 API 读取 |
| 平台 | Windows + macOS 同步 | 平台中立核心 + 双后端，行为一致 |
| 素材 | 运行时目录加载、控制台导入 zip（**递归扫描全部 webm，无 manifest/videos 结构**）；**多桌宠注册 + 切换当前桌宠** | 动作分类由管理端配置；发布物仅二进制 |
| 控制层 | **单一本地 HTTP 服务**（127.0.0.1）；不提供 CLI / MCP / Hooks | 一通道覆盖控制 + 前端托管；协议简单，Agent/脚本直接调 API |
| 管理界面 | **浏览器控制台**，前端编译期内嵌二进制 | 跨平台一致、前端生态成熟；保持单文件分发 |
| **配置文件** | **单一 YAML（仅系统级引导）**：`database_path / assets_dir / console_port / log_level`；其余配置全部入 SQLite | 引导项必须先于数据库存在；可手改；**无历史迁移，直接废弃 config.json**；自启以系统机制（注册表/LaunchAgent）为准，不入 YAML |
| **数据库** | **SQLite（rusqlite bundled）**，独立 `.db` 文件、**不内嵌二进制**；首次运行指定路径、无库自动生成 | 结构化数据（素材集注册 / 动作权重 / 程序设置 / 导入记录 / 聊天）统一入库；单文件、零服务、跨平台 |
| **桌宠模型** | **多桌宠：导入注册 + 切换当前桌宠；桌面始终只显示一只**（不做同屏） | 多角色素材按桌宠隔离配置 |
| 许可 | MIT（本项目）+ 上游素材 MIT 声明 | 无许可负担，保留可替换性 |

### 1.3 新增选型要点

- **rusqlite（bundled）**：内置 SQLite 源码随 crate 编译，无需系统 sqlite；
  Windows 需与 `crt-static` 兼容（cc crate 检测 `crt-static` 自动切 `/MT`，**待实机验证**；
  兜底方案同 libvpx：vcpkg `sqlite3:x64-windows-static` 静态库直链）。
- **YAML 解析**：`serde_yaml` 0.9（已归档但功能稳定）或社区维护 fork `serde_yml`；
  配置结构简单，任选其一（倾向 `serde_yml` 保持维护）。
- **动作预览**：服务端复用 vpx 解码器逐帧输出 PNG（精确复刻桌宠渲染，含合成/缩放）；
  备选前端 `<video>` 直播 webm（浏览器对 alpha 通道支持不一致）。

## 2. 技术要点（现状实现）

- **渲染**：Windows `UpdateLayeredWindow`（BGRA premultiplied，AC_SRC_ALPHA）；
  macOS 无边框透明 NSWindow + NSView 逐帧 drawRect → CGBitmapContext → CGImage；
  缩放/镜像共享 `gfx::scale_bgra`（4 档：50%/72%/85%/100%）。
- **穿透与交互**：Windows `WM_NCHITTEST`（像素 alpha<128 → HTTRANSPARENT）+ `WM_SETCURSOR`
  手型；macOS `ignoresMouseEvents` 按光标位置逐 tick 切换（窗口服务器层真穿透；
  代价：光标样式失效，悬停手型仅 Windows）。
- **菜单/托盘/自启**：数据驱动 `MenuEntry`；托盘右键完整菜单（含「打开控制台」）；
  Windows `Shell_NotifyIconW` / macOS `NSStatusItem`；自启注册表 / LaunchAgent。
- **构建**：build.rs 探测静态 libvpx（`VPX_LIB_DIR` > vcpkg > brew；
  macOS 传 `.a` 绝对路径强制静态，避免 ld 优先 dylib）；
  `opt-level=z + lto + strip`；打包脚本 `tools/pack.ps1` / `pack.sh`。
- **本地 HTTP 服务**：tiny_http 内嵌线程；默认端口 18686、冲突回退随机、端口写
  `control.json`；静态托管内嵌前端 + `/api/*`；仅绑 loopback + Host 校验。

## 3. 当前状态（已完成，简要）

- **P1 macOS 真机验证 ✅**：真机构建链（brew libvpx）、渲染/穿透/拖拽/位置/单实例/
  状态栏菜单；LaunchAgent 自启未完整验证。
- **P2 素材分离 + Windows 打磨 ✅**：素材运行时目录加载（exe 37.9MB → 1.5MB）、
  manifest 规范、zip 打包、单实例锁、exe 图标。
- **M1 导入闭环 ✅（2025-08）**：内嵌 HTTP 控制服务、JSON API、托盘「打开控制台」、
  前端工程（状态/导入/配置三页，编译期内嵌）、zip 导入管线（校验/解压/热加载）、
  发布物仅二进制（macOS .app+dmg / Windows 单 exe）。
  **注**：M1 导入管线基于 manifest.json + videos/ 目录的旧素材包格式，
  阶段 1/2 将改造为「仅扫描 webm + 管理端配置动作分类」。
- **Windows 全功能 ✅ 并验证**：透明/穿透/点击回应/拖拽/自主移动/托盘/手型；
  say 气泡修复（GDI 几何圆角 alpha 遮罩 + 换行）；**内存优化**——全部动画共享解码器，
  48MB 恒定（原随动作累积 +6MB/动画，压测 51 段动画 Δ+0.02MB）。
- **工程 ✅**：单 crate 标准布局 / MIT LICENSE / git 历史重构（移除 Tauri 实现）。

## 5. 路线图（后续要做什么）

> 阶段 1-4 取代原 M1/M2/M3 规划（M1 已完成，M2/M3 被本方向吸收扩展）。
> 顺序理由：数据层是控制台与配置化的一切前提（先有 SQLite + YAML，才有可编辑的配置）；
> 控制台重构提供管理入口；行为引擎接线让配置真正生效；预览与打磨收尾。

### 阶段 1 —— 数据层重构

- rusqlite（bundled）接入：连接管理、schema 建表、版本化迁移；
- 单一 YAML 配置文件（系统级引导）+ 首次运行自动生成 / 建库（**无旧配置迁移**）；
- 素材包格式改造：导入仅递归扫描 webm，去掉 manifest / videos 校验；
- Windows `crt-static` 兼容验证（cc crate /MT，兜底 vcpkg 静态 sqlite）。

### 阶段 2 —— 控制台重构

- 总览页（当前桌宠状态 + 快捷指令 + 配置摘要 + 系统信息）；
- 桌宠管理页（列表 / 导入 / 切换 / 删除 / 动作配置：动画 → 触发类型 × 启用 × 权重）；
- 设置页（程序级行为 + 外观 + 系统级，标注存储位置）；
- 新 API：`/api/pets*`、`/api/settings`、`/api/system`。

### 阶段 3 —— 行为引擎接线

- 程序级参数生效：闲时占比 / 动作触发间隔 / 移动参数 / 缩放档位（替换 `state.rs` 常量）；
- 桌宠级权重生效：`pick` 改为按权重随机。

### 阶段 4 —— 预览与打磨

- 服务端动作预览（复用解码器输出 PNG 帧）；
- 导入体验细化（重复导入 / 覆盖确认 / 失败报告）；
- 单元测试补齐。

### 后续（远期方向）

- 调试面板（调用并查看对外 HTTP API）；
- 聊天面板与对话能力（本地规则优先，Agent 接入可选）；
- AI 生成素材（描述 → 视频生成 → HSV 抠像 → 归一化 → 打包为 zip 素材包）。
