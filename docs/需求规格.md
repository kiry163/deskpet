# deskpet 需求规格（V2 草案）

> 状态：**V2 草案**（2025-12 重写，第二版修订）。方向：**控制台与配置规范化**——
> SQLite + 单一 YAML 分层配置、素材导入简化（仅扫描 webm）、动作配置管理、桌宠切换
> （桌面始终单只）。
> 本文记录需求与分期；技术选型与理由见《可行性分析与技术选型》。
> 原 V1（M1/M2/M3 里程碑）已随 M1 完成与方向调整归档，不再维护。

---

## 1. 方向总览

- **配置分层**：单一 YAML（仅系统级引导）+ SQLite（程序级与桌宠级全部配置与数据）；
- **素材简化**：导入包**仅含 webm 文件**，无 manifest.json、无 videos 目录结构；
  动作分类（待机 / 点击 / 拖拽 / 闲时等）由用户在管理端配置；
- **桌宠管理**：多套素材集导入注册 + 切换当前桌宠（**桌面始终只显示一只**，不做同屏）；
- **行为可调**：闲时占比、动作触发间隔等程序级参数取代硬编码常量，桌宠级动作权重可调；
- **无历史包袱**：未正式发布、无历史用户，**不做任何旧版本配置迁移**，直接废弃 config.json。

## 2. 配置架构（V2 核心）

### 2.1 分层原则

| 层 | 载体 | 内容 | 特点 |
|---|---|---|---|
| 系统级 | `deskpet.yaml`（唯一 YAML） | `database_path`、`assets_dir`、`console_port`、`log_level` | 启动前必须已知；可手改；**只此一个配置文件** |
| 程序级 | SQLite `app_settings` | 当前桌宠、位置、缩放、置顶、朝向、不移动、闲时占比、动作触发间隔、移动参数 | 控制台可编辑、热生效 |
| 桌宠级 | SQLite `pets` + `pet_actions` | 素材集注册、动作配置（动画 → 触发类型 → 权重/启用） | 按桌宠隔离 |

> 规则：YAML 只放**引导级**配置（应用能打开数据库之前就必须知道的项），其余全部进 SQLite——
> 数据库路径必须在打开数据库前得知，这是保留唯一 YAML 文件的根本原因。
> 开机自启不在 YAML：以系统机制（Windows 注册表 / macOS LaunchAgent）为事实来源，
> 由托盘菜单切换，避免双事实源漂移。

### 2.2 YAML（系统级）示例

```yaml
# deskpet.yaml —— 默认生成于配置目录；首次运行前可手动放置以指定路径
database_path: "C:/Users/me/AppData/Roaming/deskpet/deskpet.db"  # 不存在则自动建库
assets_dir: null            # 素材根；null = 默认配置目录 assets/
console_port: 18686         # 冲突时回退随机端口
log_level: info             # off|error|warn|info|debug（环境变量 DESKPET_LOG 优先）
```

### 2.3 首次运行流程

1. 无 `deskpet.yaml` → 生成默认 YAML（默认 db 路径 = 配置目录下 `deskpet.db`）；
   用户可**提前放置 YAML 或启动前手改**以指定路径（已决策，见 §9）；
2. 打开 `database_path` → 文件不存在则自动创建并建表（schema 迁移版本化）；
3. 素材根为空 → 控制台引导导入素材包。
   **不迁移旧 `config.json`**（无历史用户，直接废弃不再读取）。

## 3. SQLite 数据模型（草案）

```sql
CREATE TABLE pets (                -- 素材集（桌宠）注册表
  id TEXT PRIMARY KEY,             -- 素材集 id（时间戳/序号，净化后，兼作素材子目录名）
  display_name TEXT NOT NULL,      -- 显示名（默认 = 导入 zip 文件名，可改名）
  source TEXT NOT NULL,            -- 导入来源（zip 文件名）
  imported_at INTEGER NOT NULL,    -- unix 秒
  builtin INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE pet_actions (         -- 桌宠级动作配置：动画 → 触发类型 + 权重
  pet_id  TEXT NOT NULL REFERENCES pets(id) ON DELETE CASCADE,
  action  TEXT NOT NULL,           -- 动画名（webm 文件名 stem，素材目录内唯一）
  trigger TEXT NOT NULL,           -- click / drag / idle / turn / move / idle_act
  weight  REAL NOT NULL DEFAULT 1.0,   -- 权重；0 = 禁用
  enabled INTEGER NOT NULL DEFAULT 1,
  PRIMARY KEY (pet_id, action)     -- 一个动画只归一个触发类型
);

CREATE TABLE app_settings (        -- 程序级配置（key/value，value 存 JSON）
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);

CREATE TABLE import_log (          -- 导入记录
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  pet_id TEXT, file_name TEXT, result TEXT, detail TEXT, created_at INTEGER
);

-- 预留：chat_log（后续聊天）
```

- **动画清单以文件系统为准**：扫描素材目录内全部 `*.webm`；`pet_actions` 为其覆盖配置
  （未登记动画默认 `idle_act`、`weight=1`）；
- **默认动作配置**：导入后全部动画登记为 `idle_act`（闲时随机动作池，保证桌宠会动），
  用户在管理端逐一分配触发类型。

## 4. 桌宠管理

- **导入**：zip 素材包 → **递归扫描全部 `*.webm`**（忽略目录结构，无 manifest / videos 要求）
  → 校验每个 webm 可解码（复用解码逻辑）→ 解压到 `<素材根>/<pet_id>/` → 注册 `pets` +
  生成默认动作配置 → 加入桌宠列表（不自动切换；若当前无桌宠则自动设为当前）；
  - 画布尺寸无需 manifest：从 webm 头自动读取；
  - 文件名冲突：素材目录内同名单文件冲突时保留先导入者并告警（待细化）。
- **切换**：选择当前桌宠 → 热加载（复用现有热加载机制）；**桌面始终只显示一只**；
  程序级外观/位置为全局，切换不重置（已决策，见 §9）；
- **删除**：从列表移除注册，**默认保留素材文件**（可再次导入）；提供「连同文件删除」
  二次确认选项（已决策，见 §9）；
- **动作配置（桌宠级）**：管理端列出该桌宠全部动画 → 为每个动画分配触发类型
  （下拉）+ 启用开关 + 权重滑块；引擎按权重随机选择（替代等概率）；
- **预览**：**服务端解码出帧图**（复用 vpx 解码器，精确复刻桌宠渲染，含合成/缩放；
  已决策，见 §9）。

## 5. 行为引擎配置化

### 5.1 触发类型（对齐现有行为模型）

| 触发类型 | 现有分类 | 说明 |
|---|---|---|
| `click` | `clicks` | 点击回应 |
| `drag` | `drag` | 拖拽反馈 |
| `idle` | `idle` / `idles` | 待机动画 |
| `turn` | `turn` / `turns` | 转向动画 |
| `move` | `moves` | 移动动画 |
| `idle_act` | `acts` | 闲时随机动作池 |

> 无 manifest 后，触发类型不再由素材包声明，**全部由管理端配置**决定。

### 5.2 程序级参数（替代 `state.rs` 硬编码常量）

| 参数 | 现状常量 | 含义 |
|---|---|---|
| 闲时占比 | `P_IDLE=0.30 / P_TURN=0.40 / P_ACTS=0.80` | 待机 / 转向 / 闲时动作 / 移动分支概率 |
| 动作触发间隔 | —（随动画链） | 动画链切换节奏 |
| 移动参数 | `MOVE_MIN_PX / MOVE_MAX_PX / MOVE_MARGIN` | 自主移动范围 |
| 缩放档位 | `SCALE_STEPS=[0.5,0.72,0.85,1.0]` | 大小档位 |

- 实现：`pick_next` 等接收策略参数（默认值 = 现常量）；`pick` 改为**按权重随机**。

## 6. 控制台界面（重构）

1. **总览**：当前桌宠（名称 / 缩略预览 / 状态：当前动作、位置、朝向、缩放、可见性）
   + 快捷指令（say / play / move / quit）+ 程序级配置摘要 + 系统信息（版本 / 端口 / db 路径）；
2. **桌宠管理**：
   - 桌宠列表（卡片：缩略图 / 名称 / 动画数 / 导入时间 / 当前标记；操作：切换 / 删除；
     导入入口）；
   - 桌宠详情：**动画清单**（全部 webm，逐一配置触发类型 + 启用 + 权重）+ 预览区
     （选中动画播放）；
3. **设置**：程序级行为（闲时占比 / 触发间隔 / 移动参数 / 缩放档位）+ 外观
   （位置 / 缩放 / 置顶 / 朝向 / 不移动）+ 系统级（db 路径 / 素材根 / 端口 / 日志 / 自启，
   标注「存于 YAML」）。

## 7. API 扩展

现有 API（`state / config / pet.say / pet.play / pet.move / pet.set_state / import / quit`）
保持兼容（`/api/config` 后续收敛为 `/api/settings`）；新增：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/pets` | 桌宠列表（含当前标记）|
| POST | `/api/pets/{id}/switch` | 切换当前桌宠（热生效）|
| DELETE | `/api/pets/{id}` | 删除桌宠（默认保留文件）|
| GET | `/api/pets/{id}/actions` | 桌宠动作配置（动画 → 触发类型 / 权重 / 启用）|
| PUT | `/api/pets/{id}/actions` | 保存动作配置（热生效）|
| GET | `/api/pets/{id}/preview?action={name}&frame={n}` | 动作预览帧（PNG）|
| GET / PATCH | `/api/settings` | 程序级配置（DB，热生效）|
| GET | `/api/system` | 系统级配置（YAML）+ 版本信息 |

- `/api/import` 语义更新：zip 递归扫描 webm、无 manifest 校验、注册入桌宠列表。

## 9. 关键决策记录

| # | 决策项 | 结论 |
|---|---|---|
| 1 | 数据库路径首次指定 | 默认生成 `deskpet.yaml`（默认 db 路径）+ 启动前手动放置/手改指定 |
| 2 | 桌宠形态 | **多桌宠切换激活，桌面始终单只**（不做同屏多只） |
| 3 | 配置分层 | **YAML 仅引导级**；程序级/桌宠级全部入 SQLite |
| 4 | 动作预览 | **服务端解码出帧图**（精确复刻渲染） |
| 5 | 删除桌宠 | 默认仅移除注册、保留素材文件；提供连带删除的二次确认选项 |
| 6 | 素材包格式 | **仅 webm 文件**，无 manifest.json / videos 结构；动作分类由管理端配置 |
| 7 | 旧版本兼容 | **不做迁移**：废弃 config.json，无历史用户 |
