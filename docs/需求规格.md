# deskpet 需求与方向（发展设计）

> 状态：**草案**（2025 重写）。方向：以「**配置可自定义**」为核心。
> 本文记录需求与分期；技术选型与理由见《可行性分析与技术选型》。

---

## 1. 方向总览

核心：**配置可自定义**——素材、行为、外观、对话均可配置。四条线：

- **素材可导入**：角色素材经控制台导入（校验/预览/切换），不随软件分发，发布物仅二进制；
- **行为可调**：行为策略（动作概率/移动参数/缩放档位/模式预设）可配置；
- **界面可管理**：浏览器控制台统一管理（状态/指令/配置/导入/调试/聊天）；
- **能力可调用**：本地 HTTP 服务对外暴露能力，Agent/脚本直接调用。

| 需求域 | 目标 | 阶段 |
|---|---|---|
| 素材导入与角色切换 | 控制台导入素材/角色，校验 + 预览 | P4 基础 / P5 打磨 |
| 行为策略配置 | 概率/移动参数/模式预设 | P3 |
| 控制能力 | 单一本地 HTTP 服务，JSON API 对外可编程 | P4 |
| 管理控制台 | 配置/调试/聊天一体的浏览器界面 | P4 基础 / P5 完整 |
| 对话与气泡 | 桌宠气泡输出文字；控制台聊天 | P4 气泡 / P5 聊天 |
| 配置与数据 | 单一 config.json + SQLite（程序数据）| P4 |
| AI 生成素材 | 描述 → 生成 → 导入 | P5（远期）|

---

## 2. 配置与数据（P4）

- **单一配置文件** `config.json`（用户偏好，可手改、热生效）：
  `assets_dir` / `character` / `rx/ry` / `facing_right` / `scale` / `always_on_top` /
  `no_move` / `behavior`（§4）/ 控制台端口等；**不拆分多个配置文件**。
- **SQLite**（`deskpet.db`，rusqlite 内嵌；仅存程序数据，不存用户手改配置）：
  素材库索引（导入记录、角色注册）、聊天记录、（可选）调试历史。
- 运行时文件（非用户配置）：`control.json`（HTTP 服务实际端口，供外部程序发现端点）、
  日志、单实例锁。
- 数据目录：macOS `~/Library/Application Support/deskpet/`；Windows `%APPDATA%\deskpet\`。

---

## 3. 素材、角色与导入（P4 基础 / P5 打磨）

- 素材**不内嵌**二进制、**不随 zip 分发**；发布物仅二进制，素材由用户经控制台导入
  （首次使用无素材时，控制台引导导入或指向已有素材目录）。
- 角色 = 素材包：`videos/`（VP9+alpha webm）+ `manifest.json`；素材根与角色由配置
  `assets_dir` / `character` 指定（现状已支持目录加载与 manifest / 子目录 / 关键词
  三种分类兜底）。

manifest 规范（现状已落地）：

```json
{
  "id": "shenshen",
  "display_name": "深神",
  "canvas": { "w": 640, "h": 360 },
  "actions": {
    "idle":  ["待机呼吸休闲"],
    "turn":  ["东张西望"],
    "moves": ["螃蟹走路", "原地漂浮踏步", "原地左转奔跑"],
    "clicks":["点击回应 - 开心跃动", "点击回应 - 害羞惊讶"],
    "drag":  "被鼠标拖拽悬空反馈",
    "acts":  ["玩魔方", "吐泡泡"]
  }
}
```

导入策略（P4 落地，P5 打磨）：

1. 来源：本地目录选择 / zip 素材包 /（远期）AI 生成产出；
2. 流程：复制到素材根 → 校验（manifest 合法、webm 可解码、缺省动作兜底）→ 预览 →
   注册入库（SQLite）→ 切换角色；
3. 失败处理：单文件失败跳过并告警；整包失败提示无效，不污染素材根。

---

## 4. 行为策略配置（P3）

- `behavior` 配置块：`mode`（calm / balanced / lively 预设，可被 weights 覆盖）+
  `weights`（idle/turn/act/move）+ `move`（min_px / max_px / margin）+
  `scale_steps`；缺省 = 现常量（P_IDLE=0.30 / P_TURN=0.40 / P_ACTS=0.80、
  MOVE_MIN_PX=60 / MOVE_MAX_PX=240 / MOVE_MARGIN=20）。
- 实现：`state::pick_next` 等接收策略参数（默认值 = 现常量），`config.rs` 扩展结构。

---

## 5. 控制能力（本地 HTTP 服务，P4）

- **单通道**：桌宠进程内嵌 HTTP 服务（`tiny_http`，后台线程），绑定 127.0.0.1；
  默认端口 18686（可配置），冲突回退随机端口，实际端口写 `control.json`；
- 不提供 CLI / MCP / Hooks 独立通道——外部 Agent / 脚本直接调用 HTTP API 自行编排，
  本项目仅保证 API 稳定与文档化；
- 同一服务还托管管理前端（§6）。

API：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 管理前端页面（静态资源）|
| GET | `/api/state` | 当前状态（动作/位置/朝向/缩放/可见性）|
| GET / PATCH | `/api/config` | 读配置 / 改配置（热生效，写同一 config.json）|
| POST | `/api/pet/say` | 说话：`{text, duration_ms?}`，气泡 + 指定时长 |
| POST | `/api/pet/play` | 播放动作：`{action}`（精确名 → 语义名 → 最近匹配）|
| POST | `/api/pet/move` | 移动：`{x, y}`（归一化 0..1）|
| POST | `/api/pet/set_state` | 运行时状态（不落盘）：`{no_move?, always_on_top?, scale?, visible?, facing_right?}` |
| POST | `/api/quit` | 退出 |
| GET | `/api/events` | （可选，P4 后期）SSE 事件（action_started / action_ended）|

- 响应：`{ok: true, data?}` / `{ok: false, error}`；
- 安全：仅绑 loopback + 校验 `Host`/`Origin` 头（拒绝跨站调用与 DNS rebinding），
  个人使用不鉴权（如需可加随机 token 写入 control.json）；
- 桌宠侧：外部指令以**高优先级**插入动画链状态机；`say` 气泡为平台层绘制
  （Win32 GDI / AppKit 文本），不依赖素材。

## 6. 管理控制台（浏览器，P4 基础 / P5 完整）

- **承载**：托盘菜单「打开控制台」→ 系统默认浏览器打开 `http://127.0.0.1:<port>/`；
  前端 `web/`（Vite + React + TS）构建产物**编译期内嵌进二进制**
  （`include_bytes!` 资源表 / `rust-embed` / `include_dir`），缺失时内嵌占位页兜底；
  开发期用 vite dev + 代理，或 `DESKPET_CONSOLE_DIR` 指向 `web/dist` 免重编译调试。
- **功能**：
  - 状态与指令：状态面板（动作/位置/朝向/缩放/可见性）、指令面板（say/play/move/quit）；
  - 配置表单：缩放/置顶/不移动/行为策略（依赖 P3）/角色切换；写同一 config.json，热生效；
  - 导入：素材与角色导入（策略见 §3）；
  - **调试面板**：列出并直接调用对外 HTTP API（含 Agent 将调用的接口），
    展示请求/响应，便于联调与排查；
  - **聊天**（P5）：对话面板与桌宠聊天，桌宠以气泡输出文字（§7）。

---

## 7. 对话与气泡（P4 气泡 / P5 聊天）

- 气泡：`say` API 触发，平台层绘制文字气泡；后续可联动口型/动作素材；
- 聊天：控制台聊天面板 → say/play 指令 → 气泡输出；对话能力后续接入
  （本地规则优先，Agent 接入可选）。

---

## 8. AI 生成素材（P5，远期）

复用 [dsh-pet 的 MIT 生成管线](https://github.com/PC2005-cloud/dsh-pet/blob/master/DESIGN.md)：
提示词（角色 + 动作分解）→ 视频生成 API（绿幕 16:9）→ HSV 抠像
（绿相 70~170° 且 饱和度/明度 ≥0.15）→ 归一化（统一画布/居中/脚底锚点）→
转码 VP9+alpha webm → 素材包（videos + manifest）。

控制台内：描述角色 → 选动作模板（内置提示词库为起点）→ 生成/预览 → 导入；
外部 API 成本与条款届时再定。
